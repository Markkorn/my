# Сказки для ПК

Мини-приложение для чтения коротких сказок на компьютере. Встроены фильтры по настроению, поиск и переключение темы.

## Как открыть

1. Откройте `index.html` в браузере.
2. Выберите сказку в списке слева или нажмите «Случайная сказка».

## Возможности

- фильтр по настроению и поиск по названию;
- переключение светлой/тёмной темы;
- настройка размера текста.
