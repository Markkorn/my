# Сказки для ПК

Мини-приложение для чтения коротких сказок на компьютере. Встроены фильтры по настроению, поиск и переключение темы.

## Как открыть

1. Откройте `index.html` в браузере.
2. Выберите сказку в списке слева или нажмите «Случайная сказка».

## Запуск через GitHub Pages

Если хотите открыть приложение прямо из GitHub:

1. Загрузите проект в репозиторий GitHub.
2. Перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите:
   - **Source**: `Deploy from a branch`.
   - **Branch**: `main` (или нужная ветка), папка `/root`.
4. Сохраните настройки и дождитесь публикации.
5. GitHub покажет ссылку вида `https://<username>.github.io/<repo>/` — по ней приложение будет доступно.

> Примечание: `index.html` должен лежать в корне репозитория, как сейчас.

## Возможности

- фильтр по настроению и поиск по названию;
- переключение светлой/тёмной темы;
- настройка размера текста.
- профиль читателя с сохранением данных в браузере.
